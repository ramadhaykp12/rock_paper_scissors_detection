# Rock Paper Scissors Detection using YOLOV11 Model
In this project, I have tried fine-tune YOLOV11 Model from Ultralyics for rockpaper scissors object detection using labeled data from Roboflow. 

## Installation
Clone the repository by running the command below with your terminal:
```bash
git clone https://github.com/ramadhaykp12/rock_paper_scissors_detection.git
cd rock_paper_scissors_detection
```
